## Deployment

### Vercel (Recommended)

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial SkyView Electronics platform"
   git push origin main
   ```

2. **Connect to Vercel**
   - Go to https://vercel.com
   - Import your GitHub repository
   - Configure environment variables
   - Deploy

3. **Custom Domain**
   - Add your domain in Vercel settings
   - Update DNS records

### Environment Variables Needed
Currently none required for storefront phase.

For Phase 3 (Commerce), add:
- `NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY`
- `NEXT_PUBLIC_HUBTEL_MERCHANT_ID`
- `DATABASE_URL`
- `JWT_SECRET`

## Customization Guide

### Changing Business Contact Information
- Update `components/layout/Footer.tsx` - Contact section
- Update `app/about/page.tsx` - Business Info section
- Update `app/contact/page.tsx` - All contact fields
- WhatsApp links: Search for `233544185227` and replace

### Adding New Products
Edit `lib/products.ts`:
```typescript
{
  id: 'unique-id',
  name: 'Product Name',
  slug: 'url-slug',
  price: 1000,
  // ... other required fields
}
```

### Changing Colors
1. Edit `tailwind.config.js` colors
2. Use Tailwind utility classes
3. Changes apply globally

### Adding New Pages
1. Create `app/newpage/page.tsx`
2. Add navigation link in `components/layout/Header.tsx`
3. Add footer link if appropriate

### Common Tasks

- Edit `lib/products.ts`
- Modify price field
- Rebuild and deploy

**Update Business Hours**
- Edit `app/contact/page.tsx`

- Extend region list in `app/delivery/page.tsx`

### Troubleshooting

**Build Fails**
```bash
rm -rf .next
npm run build
```

**TypeScript Errors**
```bash
npx tsc --noEmit
```

**Missing Images**
- Check image URLs in `lib/products.ts`
- Verify image files exist
- Clear browser cache
